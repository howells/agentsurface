## Agent Workflow and Context Tools

These are not always full agent frameworks. They are worth tracking because they give agents safer orchestration, repeatable workflows, context compression, or bounded LLM substeps. For choosing a durable-execution runtime for agent loops, see [durable execution](/docs/agents/durable-execution).

| Tool                                                       | Website            | What it is for                                                                                                                                          | Tier        | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ---------------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [OpenProse](https://prose.md/)                             | prose.md           | Declarative Markdown contracts (`.prose.md`) that any Prose-Complete coding-agent harness runs to keep long-running agent work reviewable and versioned | Watch       | Young project (Spring 2026); promising for portable, reviewable agent workflow recipes, but track adoption before depending on it.                                                                                                                                                                                                                                                                                                                                   |
| [Trigger.dev](https://trigger.dev/)                        | trigger.dev        | TypeScript workflows, background tasks, retries, checkpointing, and AI agent jobs                                                                       | Conditional | Strong when agent work needs durable execution rather than an in-request loop.                                                                                                                                                                                                                                                                                                                                                                                       |
| [Temporal](https://docs.temporal.io/)                      | docs.temporal.io   | Durable workflow engine with retries, timers, signals, queries, and long-running execution                                                              | Conditional | Standalone Activities were reported GA in server v1.32.0 (2026-09-11; not re-confirmed against the server release notes on 2026-10-29) - a single durable step recorded without authoring a full workflow, with delayed starts and operator APIs for pausing, resuming, and batch-managing activities. Simplifies wrapping single LLM calls as replay-safe steps. Use when agent work must survive process restarts, human delays, retries, and multi-day workflows. |
| [Inngest](https://www.inngest.com/docs)                    | inngest.com        | Durable serverless functions, background jobs, retries, and event-driven workflows                                                                      | Conditional | Powers Mastra's durable agents. Good TypeScript path for event-driven agent tasks that should not run inside a request lifecycle. Recent releases add rerunning a run from a specific step, `step.score()`/`group.experiment()` for scoring and experiments (beta), a run-level AI usage summary, and OAuth for MCP clients connecting to Inngest Cloud.                                                                                                             |
| [@inngest/agent-kit](https://github.com/inngest/agent-kit) | github.com/inngest | Agent orchestration layer (networks, routing, state) built on top of Inngest                                                                            | Watch       | No release since 2025-11 as of this writing. Inngest's own durable-function primitives above remain actively developed; evaluate whether agent-kit's orchestration layer is still the right fit or whether to build directly on Inngest steps.                                                                                                                                                                                                                       |
| [Hatchet](https://docs.hatchet.run/v1)                     | docs.hatchet.run   | Open-source task queue and durable workflow engine                                                                                                      | Watch       | Useful when teams want self-hostable workflows with retries, concurrency, and observability.                                                                                                                                                                                                                                                                                                                                                                         |
| [Prefect](https://www.prefect.io/docs/v3/get-started)      | docs.prefect.io    | Python workflow orchestration for data and AI pipelines                                                                                                 | Conditional | Relevant when agent workflows are coupled to Python data processing or scheduled RAG pipelines.                                                                                                                                                                                                                                                                                                                                                                      |
