Agent Surface is a guide to making software usable by agents. Agents reach a product through many contact points: they read repository instructions and documentation, call APIs, run CLIs, use MCP tools, parse errors, retrieve data and ask for approval. Each contact point is part of the product's agent surface, and each can be designed well or badly.

The site has two parts.

The core of the guide. It covers how agents find, understand and use an existing website, app, API or CLI, and how to test that they can.

## The `surface` skill

`surface` applies the guide to a specific repository. It has three routes: Guide explains concepts and supports decisions, Audit produces an evidence-backed scorecard and plan, and Scaffold creates or extends agent surfaces and the tests that check them. The skill covers the product side only.

```sh
npx skills add https://github.com/howells/agentsurface
```

To use it, open Claude Code or Codex in your project and run the skill: type `/surface` in Claude Code or `$surface` in Codex. With no other instruction it audits the codebase, scores each part of its agent surface and returns the findings with a plan. Ask a question after the command to get an explanation instead, or name a surface, such as `/surface mcp`, to build or improve that part.
