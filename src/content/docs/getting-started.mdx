## If you are starting from zero

For an existing product, this order gets the most value earliest:

1. Write accurate context files: `AGENTS.md` and any tool-specific files that import it.
2. Make content discoverable: robots.txt policy, `llms.txt`, structured data, sitemap and Markdown routes.
3. Make command output parseable: JSON, stable exit codes and strict input validation.
4. Publish machine-readable contracts: OpenAPI, schema metadata and tool definitions.
5. Add recovery paths: RFC 9457 errors, retry guidance, idempotency and trace IDs.
6. Secure programmatic access: scoped credentials and OAuth protected resource metadata.
7. Expose tools deliberately: an MCP server with a curated tool set, annotations and approval for risky actions.
8. Test real tasks: eval cases, traces, CI gates and a before-and-after scorecard.
