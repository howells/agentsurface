This is the canonical list of model IDs Agent Surface uses in examples. Every model-ID string in the docs and in the template kits must appear here. `scripts/check-docs-integrity.mjs` parses this page's code-formatted IDs into an allowlist and flags any model-ID-shaped string elsewhere in the corpus that is not on it - including bare Anthropic role aliases (`opus-4-7`) and prose model names (`Opus 4.8`). Update this page first, then run the sweep.

Verified against provider documentation on 2026-10-29.

## Anthropic

| Model      | API ID              | Role                | Notes                                                                                              |
| ---------- | ------------------- | ------------------- | -------------------------------------------------------------------------------------------------- |
| Fable 5.1  | `claude-fable-5-1`  | Flagship            | Supersedes Fable 5; highest-capability publicly available model for deep reasoning and long tasks. |
| Opus 5.5   | `claude-opus-5-5`   | Recommended default | Released 2026-09-22. Supersedes Opus 5; 1M context, effort control.                                |
| Sonnet 5.5 | `claude-sonnet-5-5` | Balanced            | Released 2026-09-28. Supersedes Sonnet 5; fast iteration and everyday agent loops.                 |
| Haiku 5.5  | `claude-haiku-5-5`  | Fast / low cost     | Released 2026-10-07. Supersedes Haiku 4.5; cheap evals, classification, high-volume calls.         |

All four current models have a 1M-token context window and 128K synchronous output. Current IDs are dateless - do not append a date suffix.

Anthropic also documents **Mythos**, a restricted tier above Fable 5.1 for approved Project Glasswing participants. Its IDs are published (claude-mythos-5-1, claude-mythos-5), but access is restricted, so they are deliberately not on the allowlist; do not reference them in general examples.

**Retired 2026-06-15:** Opus 4 and Sonnet 4. **Retired 2026-08-05:** Opus 4.1. **Deprecated 2026-09-30:** Sonnet 4.5, retiring 2026-11-30.

**House policy, not provider retirement:** Opus 4.7, Opus 4.8, and Sonnet 4.6 are still active on the Claude API (retirement is not sooner than 2027-04-16, 2027-05-28, and 2027-02-17 respectively), and so are Opus 5, Fable 5, Sonnet 5, and Haiku 4.5. This repo keeps them off the allowlist so examples pin current models, and the model-ID check flags them, including bare aliases and prose mentions. Use them only in your own code, where a deliberate pin is fine. **Superseded 2026-09-22:** Opus 5 and Fable 5. **Superseded 2026-09-28:** Sonnet 5. **Superseded 2026-10-07:** Haiku 4.5. Replace default pins with `claude-opus-5-5`, flagship pins with `claude-fable-5-1`, balanced pins with `claude-sonnet-5-5`, and fast pins with `claude-haiku-5-5`.

Anthropic API version `2026-10-21` removes `temperature`, `top_p`, and `top_k` (a request that sends them returns a 400); new major SDKs default to it. Do not set them in examples.

## OpenAI

| Model         | API ID          | Role       | Notes                                                                        |
| ------------- | --------------- | ---------- | ---------------------------------------------------------------------------- |
| GPT-6 Astra   | `gpt-6-astra`   | Flagship   | Highest-capability OpenAI tier.                                              |
| GPT-6.1 Sol   | `gpt-6.1-sol`   | Reasoning  | Ultrafast option launched 2026-10-08.                                        |
| GPT-6.1 Terra | `gpt-6.1-terra` | Balanced   | Launched 2026-10-26. Most capability per dollar for everyday agent work.     |
| GPT-6 Luna    | `gpt-6-luna`    | Value tier | Fastest and cheapest; the default wherever a cheaper OpenAI model is wanted. |

All four have a 1.05M-token context window and 128K maximum output. In prose the family names are GPT-6 and GPT-6.1; `gpt-6` and `gpt-6.1` are allowlisted for that prose use only and are not API IDs - never pin them.

**Superseded 2026-10:** the GPT-5.6 tiers (Sol, Terra, Luna) remain available but the GPT-6 family replaces them in examples, as GPT-5.5 and GPT-5.4 were replaced earlier - the model-ID check flags remaining GPT-5.6, GPT-5.5, and GPT-5.4 pins. The o-series reasoning models are retiring model by model, not on one date: o1, o1-pro, o3-mini, and o4-mini were shut down on 2026-10-23, the deep-research variants on 2026-07-23, and o3 and o3-pro are scheduled for 2026-12-11. Check each ID on OpenAI's deprecations page. Do not use any of them in examples.
